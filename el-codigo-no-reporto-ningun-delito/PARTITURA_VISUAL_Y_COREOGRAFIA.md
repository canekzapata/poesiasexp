# VISUAL SCORE AND CHOREOGRAPHY

## A browser that behaves like a novel, an archive and a market under pressure

**Status:** governing visual document · version 0.1  
**Primary medium:** typography, browser space, links, fields and moving language  
**Priority:** reading before spectacle

---

## 1. Visual proposition

The work should look as if an exact editorial system is gradually discovering that its categories are participating in the case.

At first the page is calm, sparse and credible. As the visitor acts, labels acquire prices, paragraphs lose words, citations cross windows, buttons reproduce and the grid begins treating the reader's actions as documents.

The visual world is not a representation of blockchain infrastructure. It is a demonstration of how interfaces convert language into property, action and evidence.

> Nothing moves merely to appear alive.  
> Something moves because its custody, source, price or grammatical function has changed.

---

## 2. The three visual ancestors

The piece combines three traditions without reproducing a specific existing design.

### Editorial page

- strong typographic hierarchy;
- generous reading fields;
- captions, footnotes and marginalia;
- long-form prose treated with dignity;
- tension between image, text and white space.

### Documentary interface

- case numbers;
- evidence labels;
- restrained tables;
- status fields;
- revision histories;
- coordinates and relation lines.

### Browser-native net art

- hyperlinks as visible propositions;
- windows and tabs as narrative positions;
- text that changes materially in the DOM;
- address bar and history as memory;
- responsive layout as recomposition;
- loading, focus, selection and disappearance as authored events.

The result should not look like a newspaper pasted onto a dashboard. These three logics must act upon one another.

---

## 3. Anti-aesthetic

Avoid:

- green terminal text;
- matrix rain;
- glowing blockchain nodes;
- anonymous hooded figures;
- generic glitch;
- floating coins;
- cyberpunk neon as default atmosphere;
- luxury NFT black-and-gold branding;
- glassmorphism dashboards;
- illegible brutalism mistaken for net art;
- constant motion;
- a dense node graph offered as explanation.

The piece may become strange, but its strangeness should emerge from operations upon readable evidence.

---

## 4. Initial appearance

The first screen should be almost disarmingly composed:

- off-white or softly luminous field;
- dark text with high contrast;
- one restrained accent color derived from the edition;
- narrow case index;
- wide reading column;
- faint 16 × 16 chamber grid present as background or margin;
- a single active button;
- no visible market ticker;
- no crowded navigation.

The page earns the reader's institutional trust before revealing its appetite.

---

## 5. Page anatomy

Desktop composition uses four functional zones.

```text
┌──────────────┬──────────────────────────────┬──────────────┐
│ CASE INDEX   │                              │ EVIDENCE /   │
│              │       READING FIELD          │ PORTFOLIO    │
│ 256 GRID     │                              │              │
│              │                              │ RECEIPTS     │
├──────────────┴──────────────────────────────┴──────────────┤
│ ROUTE / STATUS / SOUND / TEMPORARY ACTIONS                │
└────────────────────────────────────────────────────────────┘
```

### Case index

Shows chamber position, time, evidence family and route trace. It can begin nearly blank.

### Reading field

Holds the literature. It must remain visually dominant in calm chambers.

### Evidence / portfolio

Shows what the visitor can currently claim, carry or owe. It can collapse completely during intimate passages.

### Route / status field

Contains navigation consequences, sound control and temporary actions. It should never resemble a conventional app toolbar.

On smaller screens these zones become sequential layers rather than compressed columns.

---

## 6. The 16 × 16 grid

The grid is the work's global map and abstract image.

It represents all 256 chamber coordinates. It does not promise that all are reachable.

### Cell states

| State | Visual behavior |
|---|---|
| unvisited | fine empty outline |
| reachable | quiet pulse or increased contrast |
| visited | stable fill |
| retained | inner mark or double boundary |
| surrendered | cut corner or missing edge |
| priced | small monetary/rate tick |
| stolen | offset cell with visible displacement |
| burned | outline plus ash-like residue, no content fill |
| canonical | clean solid field, source mark absent |
| inherited | diagonal relation from prior route |
| unavailable | void that deforms neighboring alignment |

Color cannot be the only carrier of state.

### Grid behavior

At entry, the grid appears architectural. During investigation it becomes navigational. During the run it becomes a market surface. At the report it resembles a completed archive. On return it is revealed as the image of the visitor's route.

---

## 7. Typography

The system should use a small, disciplined type palette.

### Reading face

A highly readable serif or humanist face for testimony, reflection and long documents.

Qualities:

- comfortable at long lengths;
- distinctive italics;
- clear quotation marks;
- strong diacritics and symbols;
- not overly nostalgic.

### Administrative face

A neutral sans serif for interfaces, labels, metadata and institutional language.

### Technical face

A monospace used sparingly for hashes, addresses, checksums, receipts and binary chamber coordinates.

The project should not use monospace as a generic sign of technological seriousness.

---

## 8. Voice through typography

Voice distinctions are subtle and consistent:

- Investigator: serif with visible marginal structure.
- Witness: generous leading and less constrained measure.
- Continuity Office: controlled sans serif, formal spacing.
- Archive: catalog labels, rules and small provenance fields.
- Market: compact display hierarchy, prices aligned with language.
- Wallet / contract: monospace or tabular rhythm, never terminal cosplay.
- Interface: imperative sans serif.
- Artist: materially preserved fragments whose form depends on source—email, folder list, transcript—not an invented “handwriting font.”

Attribution loss should be perceptible because the host typography gradually absorbs the sentence.

---

## 9. Reading measure

Long prose should remain within an accessible measure, approximately 55–80 characters per line depending on type and viewport.

The layout can destabilize around it, but the text itself should not continually stretch, rotate or flee.

During proliferation, reading columns may narrow as interface language occupies space. The result must remain readable and later return to a calm measure.

---

## 10. Four historical times

The times do not require four unrelated themes. They are transformations of one visual grammar.

### T0 — Alleged past

- porous margins;
- material textures used sparingly;
- uncertain alignment;
- annotations near objects;
- gaps that feel unclassified.

### T1 — Surviving record

- hard rules;
- fixed fields;
- checksum blocks;
- visible blank values;
- exact alignment around incomplete content.

### T2 — Active inquiry

- relation lines;
- movable evidence;
- active buttons;
- portfolios and prices;
- visible state transitions.

### T3 — Retrospective future

- elegant simplification;
- cleaner typography;
- fewer qualifiers;
- hidden source mechanics;
- institutional completeness.

The future should look calmer than the inquiry because conflict has been moved out of view.

---

## 11. Evidence forms

Each family has a recurring geometry.

### Signature

Narrow horizontal line, message block, address and verification seal. Identity label floats separately and can be removed.

### Photograph

Image field with recto/verso relation. Zoom narrows peripheral context rather than merely enlarging pixels.

### Catalog

Page spreads, staples, index alignment and materially measured gaps.

### Collector

Profile fields connected by citation lines. The absent portrait remains a person-sized blank.

### File

Nested versions sharing one frame. Stable identifier remains fixed while visual behavior changes behind it.

### Sale

Price and language occupy the same baseline. Numbers can replace adjectives visibly.

### Artist / witness

Longer textual fields, source-specific material forms and breathing space.

### Investigator / route

Marginal notes, route traces, credentials and forms that progressively resemble the visitor's interface state.

---

## 12. Hyperlinks

A hyperlink is a claim that two things should be understood together.

Links should communicate relation type without overexplaining:

- evidence relation: fine straight rule;
- inferred relation: interrupted or conditional rule;
- generated adjacency: faint temporary rule;
- market relation: value mark at midpoint;
- temporal relation: line crossing the grid's time boundary;
- stolen relation: label visibly detached from source;
- return relation: line that loops behind or around the reading field.

Text links retain familiar affordances: recognizable, focusable, underlined or otherwise unambiguous.

---

## 13. Buttons

Buttons are verbs with legal and grammatical consequences.

They should resemble text entering an executable state rather than conventional glossy controls.

Possible anatomy:

```text
[ PURCHASE DATE ]
retain: 1998
surrender: caption + question mark
```

Before an irreversible action, the button expands to reveal consequence. Confirmation should be meaningful, not repetitive.

Button states:

- available;
- priced;
- collateralized;
- borrowed;
- proliferating;
- stolen;
- already cited;
- unavailable because its verb has moved.

---

## 14. Button proliferation

Proliferation follows semantic descent.

Starting action:

> LOCATE OWNER

Descendants:

> LOCATE ADDRESS  
> LOCATE REGISTERED AGENT  
> PURCHASE JURISDICTION  
> VERIFY DISSOLUTION  
> LOCATE AUTHORITY TO VERIFY

Visual choreography:

1. original button expands its boundary;
2. descendants emerge from one edge;
3. relation lines remain visible;
4. children occupy adjacent cells or margins;
5. text field contracts but does not become unreadable;
6. at density limit, descendants begin replacing ancestors with receipts;
7. after the run, the family collapses into a single administrative summary.

Proliferation should reveal a bureaucracy growing from one verb.

---

## 15. Density limits

Maximum simultaneous interactive elements should be constrained by viewport and input mode.

Principles:

- no more elements than can retain readable labels;
- off-screen descendants appear in an index, not as invisible focus traps;
- keyboard navigation follows semantic ancestry;
- proliferation pauses when an irreversible decision requires reading;
- reduced-motion mode uses progressive disclosure rather than spatial expansion;
- mobile layout uses nested sheets or stacked relations.

Madness comes from logical excess, not inaccessible chaos.

---

## 16. Word theft

Word theft is the signature choreography of the work.

Sequence:

1. eligible word receives a nearly imperceptible custody mark;
2. action is offered elsewhere;
3. on acceptance, the word separates from its line;
4. surrounding text reflows around a measured blank;
5. the word crosses a visible relation path;
6. it enters its new host;
7. its type gradually conforms to the host;
8. the blank remains and can be inspected;
9. custody history remains available until laundering.

The word should remain readable throughout. Avoid glitch disintegration.

---

## 17. The blank

When language is removed, whitespace is evidence.

Different blanks:

- measured word gap;
- missing catalog page;
- absent portrait;
- empty metadata field;
- burned source rectangle;
- unavailable chamber in the grid;
- silence after a voice note;
- missing inner voice in a chord.

The piece should resist filling every absence with explanation.

> A blank is not lack of design. It is a record of custody no longer visible.

---

## 18. Laundering choreography

A sentence returning under cleaner provenance undergoes:

1. loss of source texture;
2. reduction of quotation marks;
3. shortening of attribution;
4. removal of qualifiers;
5. alignment to institutional grid;
6. increase in typographic confidence;
7. disappearance of transfer trail;
8. eventual incorporation into navigation or title.

Example:

```text
“I think the screen went blue.”
        ↓
Witness recalls a blue screen.
        ↓
Blue-screen event documented.
        ↓
THE ORIGINAL BLUE-SCREEN BEHAVIOR
```

The transformation should be slow enough for comparison when first encountered, then instantaneous after canonization.

---

## 19. Prices

Price should inhabit the sentence, not sit in a separate shopping panel.

Examples:

- a number occupies the position of a sold adjective;
- the width of a price displaces a caption;
- an offer appears beside a question mark;
- testimony retains a small accumulated-return figure after its language disappears;
- market confidence changes line weight rather than color alone.

The visual system must preserve the difference between real-world price cited in the case and fictional resources used by the reader.

---

## 20. Receipts

Receipts are small, exact and persistent.

At first they inhabit the margin. As evidence disappears, receipts occupy more of the page. Late in the work they can form an alternative novel composed entirely of what was exchanged.

Receipt design includes:

- sequence number;
- acquired unit;
- surrendered unit;
- authority;
- reversibility;
- chamber coordinate;
- source relation if still available.

Receipts should never be more visually seductive than intact evidence.

---

## 21. Windows and panels

Use internal windows only when they express simultaneous custody or incompatible frames.

Valid uses:

- recto and verso of photograph;
- two file versions;
- witness statement and institutional summary;
- current page and historical revision;
- another tab's shared custody;
- report and evidence it compresses.

Invalid uses:

- arbitrary floating-window nostalgia;
- decorative operating-system simulation;
- requiring the reader to manage many overlapping panels constantly.

Windows should behave as arguments about framing.

---

## 22. Browser selection

Selecting text may be part of the work without disabling ordinary copying.

Possible response:

- selected phrase reveals current custody;
- an offer appears to quote or preserve it;
- copied text carries a plain-language source note when appropriate;
- source attribution is never secretly replaced in the clipboard;
- user control remains intact.

The work can observe selection locally for interaction, but must not misrepresent data collection.

---

## 23. Scroll

Scroll expresses reading depth, not cinematic camera travel.

Possible uses:

- marginal evidence aligns with relevant sentence;
- a provenance line extends as a long passage is read;
- prior qualifications remain pinned briefly while institutional summary replaces them;
- the grid reveals vertical time layers;
- long witness passages remain stable and unfragmented.

Avoid scroll-jacking. Natural browser behavior is part of the work's trust.

---

## 24. Hover and focus

Hover may preview relations but cannot be required.

Keyboard focus must reveal the same information and remain visually strong.

Possible relation preview:

- source line illuminates;
- current word custody appears;
- prior version surfaces in margin;
- musical motif thins subtly;
- price collateral becomes explicit.

Touch devices use tap or an accessible disclosure control.

---

## 25. Browser history

Back navigation returns to prior coordinates while respecting irreversible evidence state.

Visual result:

- layout resembles the earlier chamber;
- surrendered words remain blank;
- former buttons appear as receipts;
- corrected titles show revision marks;
- the route line folds back through the grid.

The browser remembers location. The artwork remembers consequence.

---

## 26. Refresh

Refresh reconstructs edition and route state from the URL.

During reconstruction, a brief status can distinguish:

```text
EDITION RESTORED
ROUTE RESTORED
SESSION ATTENTION UNAVAILABLE
```

Do not simulate data recovery for long. The distinction is the content.

---

## 27. Multiple tabs

If supported, two tabs may create shared custody.

Visual behavior:

- a second cursor or edge marker, not a fake remote user;
- evidence held in both tabs receives doubled border;
- contradictory actions create a local custody dispute;
- closing one tab leaves a transfer receipt.

The feature must degrade gracefully and remain optional.

---

## 28. Temporal transitions

Moving among T0–T3 changes the page's level of documentary certainty.

### Past → record

Texture aligns into fields; uncertain memory becomes metadata.

### Record → inquiry

Fields become actionable; links and costs appear.

### Inquiry → future

Activity compresses into clean institutional prose.

### Future → past

Canonized language appears embedded in earlier documents as annotation, title or expectation.

Transitions should preserve at least one visible element across the change so causality can be perceived.

---

## 29. Information run

The run is the maximum-density passage.

Visual arc:

1. offers enter margins;
2. prices align beside claims;
3. buttons descend into child actions;
4. text column narrows;
5. words migrate;
6. receipts replace documents;
7. the grid fills rapidly;
8. canonical cells become clean and opaque;
9. the page suddenly clears.

There is no countdown and no penalty for pausing. Motion expresses systemic pressure, not reaction time.

---

## 30. Empty aftermath

After the run:

- nearly white or dark field depending on edition disposition;
- one intact sentence;
- several measured blanks;
- portfolio reduced to receipts;
- grid visible but quiet;
- sound absent or skeletal;
- no immediate button at the center.

The next action appears only after the reader has had time to perceive the loss, or through an explicit focus movement rather than a forced timer.

---

## 31. Investigator emergence

The investigator should not appear as a portrait or avatar.

Personhood accumulates through aligned traces:

- notes share a margin position;
- expense items form a body-shaped vertical measure only very subtly;
- the same “I” mark appears in different hands;
- credentials occupy the place previously reserved for artwork metadata;
- route actions begin aligning with investigator notes;
- the visitor's interface fields become indistinguishable from the investigator's archive.

The reader realizes a person has been graphically inferred.

---

## 32. The visitor's statement

The assembled statement appears line by line beside the actions that generated it.

```text
VERIFY SIGNATURE          → I verified the artist's signature,
PURCHASE DATE             → dated the earliest image,
ESTABLISH ORIGINAL        → established the original file
REMOVE CONFLICT           → and excluded a conflicting account.
```

At first arrows and sources are visible. Institutionalization gradually removes them until only the fluent first-person paragraph remains.

The visual horror is grammatical smoothness.

---

## 33. Final report

The report should be visually beautiful, calm and suspect.

- generous page measure;
- precise hierarchy;
- no proliferation;
- contradictions relegated to notes;
- visitor choices rendered as findings;
- TRACE identifier;
- institutional response placed prominently;
- minority sentence, if preserved, given fragile space.

The cleanest page in the work may be the one that has lost the most context.

---

## 34. Loop choreography

The report becomes the next object through visible compression:

1. paragraphs contract into findings;
2. findings become metadata rows;
3. rows become filled grid cells;
4. cells rearrange into the opening composition;
5. title changes;
6. route identifier becomes object identifier;
7. opening button returns;
8. one inherited word remains out of alignment.

The transformation should not resemble a loading screen. The reader watches history being formatted.

---

## 35. Motion vocabulary

Use a limited set of meaningful movements.

### Transfer

One unit moves between visible hosts.

### Compression

Long language becomes summary or metadata.

### Reclassification

Boundary, label and typographic host change while content remains.

### Proliferation

One executable verb produces related descendants.

### Erasure

Content disappears while its measured place remains.

### Canonization

Qualification and source trails recede; alignment becomes cleaner.

### Return

Earlier composition reappears with inherited differences.

Avoid a large animation vocabulary. Repetition teaches the reader the system.

---

## 36. Timing

Motion should be slow enough to read as causality and fast enough not to obstruct navigation.

Suggested qualitative ranges:

- focus/hover relation: immediate to brief;
- word transfer: deliberate, approximately one reading breath;
- button proliferation: staggered and interruptible;
- laundering: slower on first occurrence, faster after recognition;
- chamber transition: restrained;
- loop compression: extended authored sequence;
- reduced motion: instantaneous state change plus clear textual notice.

Exact milliseconds belong to prototype testing, not this document.

---

## 37. Color

The palette should be restrained and edition-dependent.

Functional roles:

- paper/field;
- primary text;
- secondary metadata;
- active relation;
- liability or irreversible action;
- evidence residue;
- edition accent.

Avoid assigning moral meaning simplistically: green true, red false. The work is precisely about valid operations producing questionable histories.

Contrast must meet accessibility requirements.

---

## 38. Image strategy

The disputed artwork should not be represented by a single definitive hero image.

Its visual presence may be constructed from:

- blue emission;
- cropped photographic evidence;
- version behavior;
- blank frame;
- changing file render;
- descriptions that do not agree;
- a stable boundary containing different internal states.

If we later create photographic or raster assets, each must have an evidentiary role and provenance within the fiction.

The strongest choice may be to show the photograph clearly while never showing a stable, authoritative version of the artwork itself.

---

## 39. The blue

Blue is not automatically the project's brand color. It is a disputed behavior.

Its appearances should differ:

- light on a wall;
- monitor failure;
- compression field;
- conservation reconstruction;
- institutional swatch;
- market-recognized signature color;
- afterimage following disappearance.

As the claim becomes canonical, blue may become cleaner and more reproducible while losing material complexity.

---

## 40. Responsive behavior

Responsive design should change framing without changing facts.

### Wide screen

Simultaneous reading field, grid and portfolio; visible relation lines.

### Medium screen

Reading field dominant; grid and portfolio available as adjacent layers.

### Small screen

Sequential evidence stack; persistent compact route marker; relations shown as expandable provenance trails.

No essential information depends on spatial simultaneity. Comparison tools may use a deliberate two-panel mode on small screens.

---

## 41. Gallery mode

For a London gallery or comparable exhibition:

- large but intimate display rather than spectacle wall by default;
- comfortable reading distance;
- seated or sustained interaction possible;
- directional speakers or headphones;
- physical label explaining edition versus route;
- QR handoff allowing visitor to retain a route;
- idle reset that preserves no false claim of destruction;
- optional secondary projection of the 16 × 16 grid, not duplicate text;
- lighting that preserves contrast and does not turn blue into décor.

The gallery installation should make reading socially visible without exposing private choices as surveillance.

---

## 42. Secondary grid display

If a second screen or projection is available, it can show only structural consequences:

- chambers activated;
- words in transit;
- source lines lost;
- current historical time;
- rhythm of the route;
- canonicalization spreading through cells.

It should not show the full private reading text. It acts as the public market image of an intimate inquiry.

This creates a useful split:

> On the primary screen, someone reads.  
> On the secondary screen, their reading becomes market behavior.

---

## 43. Accessibility

- semantic HTML before custom interaction;
- clear headings and landmarks;
- visible keyboard focus;
- all states communicated in text as well as form/color;
- reduced-motion mode preserving state transitions;
- sound optional and captioned;
- no timed reading requirements;
- resizable text without broken relations;
- high-contrast mode;
- descriptions for photographic and structural visuals;
- ordinary browser back and refresh remain functional;
- no inaccessible drag-only action;
- consequence dialogs readable by assistive technology;
- grid has a list or table representation.

Accessibility is not an external compliance layer. It tests whether the conceptual operations are actually intelligible.

---

## 44. Performance

The page should remain responsive during proliferation.

Conceptual priorities:

- animate transforms and opacity rather than expensive layout where possible;
- cap simultaneous moving words;
- preserve readable static fallback;
- avoid rendering all 256 chambers as full DOM documents simultaneously;
- render the grid as lightweight state cells;
- lazy-load optional media;
- keep audio synthesis efficient;
- pause nonessential motion outside the visible page;
- maintain interaction on modest gallery hardware and mobile devices.

The infrastructure should never become the accidental subject through lag.

---

## 45. Visual prototype scenes

The first prototype must prove these seven scenes:

1. **Appointment:** calm editorial trust.
2. **Photograph:** image, verso and contextual relation.
3. **Purchase:** date acquired as caption disappears.
4. **Witness:** long text protected by spacious composition.
5. **Proliferation:** one button family grows semantically.
6. **Visitor statement:** actions become fluent first person.
7. **Return:** report compresses into the next case.

If these scenes work, the larger grid can grow from them.

---

## 46. Design tests

For every visual decision ask:

1. What textual or evidentiary relation becomes clearer?
2. What changed state?
3. Can the reader perceive cause and consequence?
4. Does motion interrupt a passage that deserves attention?
5. Is the interface offering a verb or merely decoration?
6. Is absence visible without being filled?
7. Does the design reproduce a cliché the writing rejects?
8. Does the small-screen version preserve the conceptual operation?
9. Can the same meaning be accessed without sound, color or motion?
10. Will this still be legible after the novelty wears off?

---

## 47. Final visual rule

The browser is not a container for the novel. It is the institution currently handling it.

Every visual transformation must show what that handling has done.

> The page begins by presenting evidence.  
> It ends by presenting the reader in the same format.
