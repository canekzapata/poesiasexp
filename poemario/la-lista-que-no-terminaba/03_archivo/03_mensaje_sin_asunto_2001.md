# Pieza piloto 3 — Mensaje sin asunto

## Registro

- **Fecha de la pieza:** 2001-09-00
- **Tipo:** documento terminal sin encabezado completo
- **Estado:** `[F]` ficción documental / `[H]` operación hipersticional
- **Lista:** `still-here` (nombre ficticio)
- **Nota:** esta pieza es deliberadamente inventada. La fecha incompleta y la ausencia de remitente forman parte de la construcción, no de una restauración de archivo real.

## Documento

```text
From: 
To: still-here@list.invalid
Subject: 
Date: 2001-09-00 --:--:--

I found the page again.

It was not where we left it.
The address opened, but the room was empty.
There were instructions for a meeting that had already happened,
a translation waiting for its original,
and a list of names with one place left blank.

I printed the page because the screen kept changing.
The printer received the first line three times.

todavía estamos aquí

I am sending this before the connection ends.

If this arrives, do not answer.
If it does not arrive, keep the copy.
```

## Nota de archivista

`[ARC]` No puede determinarse si el documento fue enviado, escrito como ejercicio o reconstruido a partir de una copia posterior.

La fecha `2001-09-00` no representa un día real. Se conserva como señal de que el archivo no puede cerrar su propia cronología.

La frase recurrente ya no funciona como saludo. Puede ser una persistencia, una instrucción o el residuo de una firma que sobrevivió al cuerpo del mensaje.

## Cadena de custodia

1. **Producción:** remitente sin procedencia demostrable.
2. **Soporte:** archivo de texto y una impresión incompleta.
3. **Recepción:** destinatario colectivo no verificable.
4. **Copia/traducción:** ninguna traducción localizada; sólo se conserva la frase en español.
5. **Pérdida:** remitente, fecha, asunto y contexto de la página.
6. **Presentación actual:** falso documento final del primer ciclo del poemario.

## Función en el libro

Cerrar el primer arco sin resolver el misterio. La lista no continúa porque tenga vida propia, sino porque todavía existe una operación pendiente: decidir si conservar la copia equivale a responder.

## Condición de apertura

Después de este documento debe quedar una página vacía o una instrucción de archivo, no una explicación final. El libro termina cuando el lector tiene que elegir entre guardar la copia y dejar que desaparezca.
