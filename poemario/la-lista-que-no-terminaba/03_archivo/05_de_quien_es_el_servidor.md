# Pieza piloto 5 — ¿De quién es el servidor?

## Registro

- **Fecha de la pieza:** 1998-08-27
- **Tipo:** conflicto interno sobre propiedad, riesgo y custodia
- **Estado:** `[R]` reconstrucción / `[F]` voces compuestas
- **Lista:** `still-here` (nombre ficticio)
- **Nota:** no reproduce un hilo histórico ni atribuye las voces a participantes reales.

## Hilo interno

```text
From: node-east
Subject: Re: machine / responsibility

The server is not yours because you bought the disk.

Subject: Re: machine / responsibility

Subject: Re: machine / responsibility

No one owns the machine.

From: relay-03
Subject: Re: machine / responsibility

We should move the archive every three months.

From: node-east
Subject: Re: machine / responsibility

Then no one will know where anything is.

From: node-south
```

## Acuerdo provisional

```text
1. The host may turn the machine off.
2. The host may not read private files without consent.
3. The host is responsible for the bill only if the group agrees to pay it.
4. The group may copy the archive before a shutdown.
5. No copy is final.
6. If the host disappears, the archive becomes a rumor until recovered.
```

## Consecuencia

El nodo norte desconecta la máquina durante nueve días. Durante ese periodo, tres mensajes llegan a una cuenta que ya no responde. Uno contiene una advertencia. Otro contiene una dirección. El tercero sólo dice:

```text
todavía estamos aquí
```

Cuando el servidor vuelve, nadie sabe cuál de los tres debía haber llegado primero.

## Nota de archivista

`[ARC]` La discusión no demuestra que el grupo haya tenido una política de propiedad coherente. Demuestra que la ausencia de propiedad formal no elimina la responsabilidad ni el riesgo.

El archivo registra un “servidor común”, pero la máquina tiene una casa, una factura, una contraseña, una persona con acceso físico y una persona que puede apagarla.

## Cadena de custodia

1. **Producción:** hilo compuesto entre cuatro nodos.
2. **Soporte:** mensajes guardados en dos servidores y una copia en disquete.
3. **Recepción:** participantes con distintos grados de acceso técnico.
4. **Intervención:** un anfitrión desconecta el nodo sin pedir autorización colectiva.
5. **Pérdida:** orden de llegada, advertencia y dirección quedan sin contexto.
6. **Presentación actual:** expediente de conflicto y fallo de continuidad.

## Función en el libro

Romper la fantasía de que descentralización significa igualdad. El centro puede ser una persona que tiene la llave de una habitación o la capacidad de pagar una factura.
